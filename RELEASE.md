# EVI v0.2.24

This release improves visual separation of rows across the application.

## Changes

- DICOM Header Inspector now uses alternating row backgrounds.
- Hierarchical DICOM sequences remain grouped and expandable.
- Search-result and series-list alternating rows use a slightly stronger contrast.
- The light-mode neutral background is slightly darker for clearer visual structure.

## Windows executable

Download `evi.exe` from the release assets. The matching `evi.exe.sha256` file can be used to verify the download.
