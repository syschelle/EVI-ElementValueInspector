# Third-party components

## DCMTK

- Version: 3.7.0
- Project: OFFIS DICOM Toolkit
- Source: https://github.com/DCMTK/dcmtk
- Used for DICOM parsing, tag metadata and the built-in DICOM data dictionary.
- Refer to the DCMTK source distribution for its license and copyright terms.

## wxWidgets

- Version: 3.2.12
- Source: https://github.com/wxWidgets/wxWidgets
- Used for the native desktop user interface.
- Refer to the wxWidgets source distribution for its license terms.

## CMake

- Portable build tool downloaded by the Windows build script.
- Version pinned by `build_windows.bat`.
- Source: https://cmake.org/
